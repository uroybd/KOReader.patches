# KOReader Patches
A collection of patches I created primarily for personal use.

## How to use
1. To install patches, use [this guilde](https://koreader.rocks/user_guide/#L2-userpatches)
2. For patches that requires icons, copy the icons from this repository to your `koreader/icons` folder.


## Available Patches
### 2-direct-color-access-for-highlights
This patch bring the color selection menu directly in the highlight menu. Saving you clicks to change highlight color.
